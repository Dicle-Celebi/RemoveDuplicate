# Remove Duplicates from Array (Java)

This project demonstrates a simple Java program that removes duplicate values from an integer array.

## Features
- Takes 10 integer inputs from the user
- Removes duplicate values using a custom algorithm
- Returns and displays only distinct numbers

## How It Works
1. The program reads 10 integers from the user.
2. It checks each number against previously stored values.
3. Only unique values are stored in a new array.
4. The final array of distinct numbers is printed.

## Algorithm
The solution uses a nested loop approach:
- For each element, the program checks whether it already exists in the result array.
- If it does not exist, it is added.

Time Complexity: O(n²)

## Example Output
Enter ten numbers: 1 2 3 2 4 5 1 6 7 5  
The distinct numbers are: 1 2 3 4 5 6 7

## Purpose
This project was created to practice:
- Arrays in Java
- Loops (for loops)
- Basic algorithm design
- Duplicate elimination logic
